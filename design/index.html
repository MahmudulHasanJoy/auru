AURU — Secure Document Vault

Production-grade frontend preview. No server required — open any HTML file directly in your browser.

Pages

  • Login — Role-based authentication
  • Register — Student signup with password rules
  • My Vault — Document dashboard with status badges
  • Upload Document — File upload with validation
  • Officer Verification — Public code lookup portal
  • Admin Queue — Approve/reject documents

Design System

  • Single accent color (deep blue) — no gradients, no glassmorphism
  • CSS variable tokens for colors, spacing, type, radius, elevation
  • Real focus states, hover states, and disabled states
  • Mobile-responsive layout (44px+ touch targets)
  • Respects prefers-reduced-motion
  • Semantic HTML with ARIA-friendly structure

This frontend mirrors the PHP application structure exactly. When deployed to EC2, the same HTML markup will be generated by your PHP files.
